## Operational gotchas learned this session (read before editing)

- **Use the Edit/Write tools, not PowerShell, for file content**: PS 5.1 `Set-Content -Encoding utf8` writes a BOM that breaks prettier (had to strip one). For commit messages use `git commit -F <file>` — inline here-strings with embedded double quotes broke argument parsing once.
- **Prettier owns formatting**: after hand edits run `pnpm format` (it rewrites `scripts tools …`), then `format:check`. Several of your files will be reflowed — that's expected.
- **Lease + tests**: any test that opens `MilestoneOrchestrator` twice against the SAME fixture root must `await orchestrator.close()` between opens, or the second open refuses (same live pid). One-open-per-unique-root tests don't need it.
- **CAS + tests**: `StateStore.save` now requires the in-memory `revision` to equal the on-disk revision; tests that hand-write the state file after loading must re-load before saving.
- **`migrateOrchestratorState` chain**: the 1.2.0 block assigns literal `"1.3.0"` (deliberately pinned) so the new 1.3.0→1.4.0 summary rewrite always runs — never "simplify" it back to `STATE_SCHEMA_VERSION`.
- **Suite load**: the reconciliation describe timeout was raised to 60 s because the new heavyweight test files (orchestrator-identity ~60 s, aggregate-verify-identity spawns real verify.mjs runs) run in parallel. If a slow test flakes ONLY in the full run, check timeout pressure before suspecting the code.
- **verify.mjs fixture technique** (`aggregate-verify-identity.test.ts`): copies `scripts/verify.mjs` + the real evals/marker files into a temp git repo and runs it with `--stage typecheck` whose package script is a mutating `mutate.mjs`. Reuse that fixture if P0.4/P0.6 need aggregate-run coverage.
